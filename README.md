# 🎯 Man Hunt — 진짜 밖에서 하는 술래잡기

친구들과 **휴대폰 GPS**로 하는 진짜 술래잡기 웹사이트예요. 앱 설치도 로그인도 없이, 링크만 보내면 같이 놀 수 있어요.

👉 **https://leeminho811.github.io/Man-Hunt/**

- 술래는 정해진 간격마다 숨은 사람들 **위치를 받아요** (지도에 점선 동그라미)
- **자기장**이 시간이 갈수록 줄어들어요. 밖에 나가면 내 위치가 계속 들켜요!
- 술래가 숨은 사람 가까이(잡기 거리 안) 가면 **CATCH** 버튼이 빨개져요 → 누르면 잡기
- 숨는 사람은 가장 가까운 술래가 몇 m 떨어져 있는지 볼 수 있어요
- 실제 지도(OpenStreetMap 기반 거리 지도) 위에서 놀고, 🛰 버튼으로 **위성 지도**로 바꿔 건물·나무를 보며 숨을 곳을 찾을 수 있어요

## 게임 모드

| 모드 | 규칙 |
|---|---|
| 🛡️ 클래식 | 술래 vs 숨는 사람. 잡히면 탈락(관전). 시간 끝까지 한 명이라도 살아남으면 숨는 사람 승리 |
| 🧟 좀비 | 잡히면 좀비가 되어 같이 쫓아요. 끝까지 살아남은 생존자가 승리 |
| 🚓 경찰과 도둑 | 잡힌 도둑은 감옥(자기장 중심 🔒)에 갇혀요. 갇히지 않은 도둑이 감옥에 가서 “감옥 구출”을 누르면 모두 탈출! 도둑이 모두 갇히면 경찰 승리 |

## 하는 법

1. 사이트에서 닉네임을 쓰고 **방 만들기** → **링크 복사**해서 친구들에게 보내요 (또는 참여 코드 6자리를 불러 줘요).
2. 방장이 로비에서 모드와 설정을 정해요.
   - 술래 수 · 게임 시간 · 자기장 반경 · 자기장 줄어드는 횟수 · 위치 공개 간격 · 잡기 거리 · 숨는 시간
   - 참가자 옆 **술래 지정**을 누르면 그 사람이 술래, 아니면 무작위
   - 자기장 중심은 시작할 때 방장 위치. 로비 지도를 누르면 다른 곳으로 정할 수 있어요
3. **게임 시작** → 숨는 사람은 숨는 시간 동안 흩어지고, 술래 화면은 그동안 가려져요.
4. 잡혔는데 GPS 오차로 버튼이 안 켜졌다면, 숨는 사람이 직접 **잡혔어요**를 누르면 돼요.

### 꼭 알아 두기
- 처음에 **위치 권한을 허용**해 주세요.
- 게임 중에는 **화면을 켜 두세요.** 웹사이트는 화면이 꺼지면 위치를 보낼 수 없어요 (지원되는 브라우저에서는 자동으로 화면 꺼짐을 막아요).
- GPS는 10m 정도 오차가 있어요. 잡기 거리는 10~20m가 적당해요.
- 차도, 공사장, 남의 집 같은 위험한 곳은 피해서 놀아요!
- 혼자 연습해 보려면 주소 끝에 `?sim` 을 붙여요 (`…/Man-Hunt/?sim#코드`). 지도를 누르면 내 위치가 그곳으로 옮겨져요.

## 처음 한 번만: GitHub Pages 켜기

저장소 **Settings → Pages → Build and deployment** 에서 Source를 **Deploy from a branch**, Branch를 **`main` / `(root)`** 로 고르고 **Save**.
1~2분 뒤 위 주소로 열려요.

서버는 **HO’s Casino 와 같은 Firebase 프로젝트(`ho-casino`)** 를 그대로 써요. 같은 데이터베이스 규칙 안에서 동작하도록 만들어서 **Firebase 콘솔에서 따로 할 일은 없어요.**
(데이터는 `rooms/HZ<코드>/…` 에 저장돼서 카지노 방과 섞이지 않아요. 무료 한도로 충분해요 — 위치는 몇 초에 한 번만 보내요.)

## 개발

```
index.html           화면 뼈대 (첫 화면 · 참여 · 로비 · 게임 · 결과)
style.css            스타일 (모바일 우선, 어두운 네온 테마)
logic.js             게임 규칙 (모드, 자기장, 위치 공개, 잡기/구출, 승패) — DOM·네트워크 없음
app.js               Firebase 동기화, GPS, 지도(Leaflet), 화면 그리기
vendor/leaflet.*     지도 라이브러리 Leaflet 1.9.4 (BSD-2, vendor/LEAFLET-LICENSE)
firebase-config.js   Firebase 설정값 (HO’s Casino 와 같음)
database.rules.json  에뮬레이터용 규칙 사본 (실제 규칙은 ho-casino 콘솔에 있는 것과 같음)
```

- 규칙 테스트: `npm test`
- 실제 브라우저 3대 + Firebase 에뮬레이터로 하는 테스트: `npm install` 후 `npm run test:e2e` (Java 필요)
